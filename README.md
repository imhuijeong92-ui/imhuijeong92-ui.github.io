# 임희정 커리어 사이트

https://imhuijeong92-ui.github.io

개인 소유 정적 사이트입니다(GitHub Pages). 계정 종속이 없어 이직해도 그대로 유지됩니다.

## 구성
- `index.html` 한 파일 — 소개 · 경력 · 학력 · 대표 작업 · 역량 · 글 · 연락
- 글 섹션은 `<!-- POSTS:START -->` 바로 아래에 최신 글을 위로 쌓습니다.

## 업데이트
1. `index.html` 수정
2. `git add index.html && git commit -m "..."`
3. 개인 GitHub 계정으로 인증된 상태인지 확인한 뒤 `git push` → 1분 안팎으로 반영

작업용 메모(글 초안·게시 기록 등)는 `.gitignore` 로 제외돼 있어 저장소에 올라가지 않습니다.
